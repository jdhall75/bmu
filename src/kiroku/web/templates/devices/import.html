Bulk import devices

Upload a CSV or paste rows below. Required columns: name, hostname, group. Optional: port, description, make, model, role, platform, transport, driver_kind, credentials, enabled, worker_pool. Lookups for group and credentials are by name — create those first.

Existing devices are updated, not rejected. Only non-blank cells overwrite existing values — leave a cell blank to keep the current value. Groups in the CSV are added to the device's existing group membership; no groups are removed. A blank enabled cell leaves the current state unchanged (new devices default to enabled). Set worker_pool to pin a device to a specific remote worker pool (e.g. site-a); blank = default pool.
