A platform definition is a YAML file that tells scrapli how to talk to a device: what the prompt looks like in each mode, how to switch between modes, and what to run on open and close. See the annotated example below the form.

Key fields

FieldRequiredDescription
prompt_patternYesTop-level regex matching any prompt across all modes. Used as a fallback.
default_modeYesThe mode the device is in immediately after login (e.g. exec).
modesYesList of named modes. Each mode needs name, prompt_pattern, and accessible_modes.
accessible_modes[].nameYesTarget mode this mode can transition to.
accessible_modes[].instructionsYesOrdered list of instructions to reach the target mode.
failure_indicatorsNoStrings that indicate a command failed (e.g. Error:, Invalid input).
on_open_instructionsNoSent once immediately after the connection is established.
on_close_instructionsNoSent once before disconnecting.

Instruction types

TypeFieldsDescription
send_input input: "command" Send a command and wait for the next prompt.
enter_mode requested_mode: "mode-name" Tell scrapli to transition to the named mode using its defined instructions.
write input: "text" Write raw bytes without waiting for a prompt (useful for quit on close).
